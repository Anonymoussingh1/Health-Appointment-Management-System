# Health Appointment Management System

An Android app for patients to book appointments with doctors, view consultation schedules, and manage medical records.

## Download
Latest APK: see **Releases** on the right of this page.

## Features
- User registration and login
- Browse doctors and specialties
- Book and manage appointments
- Medical records and prescriptions

## Architecture
`ui/`    Activities, Fragments and ViewModels (UI layer)
`data/`  Entities, DAOs, Database, and Repository (data layer)
